pg-licht

A read-only PostgreSQL server for the Model Context Protocol.

It gives an AI assistant tools to explore schemas, read statistics and diagnose a live PostgreSQL server, plus guided prompts for the common investigations. Every tool call runs in its own read-only transaction with a statement timeout, and every catalog query is parameterized.

Install

brew tap sqlambda/pg-licht && brew install pg-licht

claude mcp add --transport stdio pg-licht \
  -e DATABASE_URL="postgresql://user:pass@host/dbname" \
  -- /usr/local/bin/pg_licht_mcp

Debian, Rocky Linux and tarball packages are on the releases page; INSTALL covers each.
